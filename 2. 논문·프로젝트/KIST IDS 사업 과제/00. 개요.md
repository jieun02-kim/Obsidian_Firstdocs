# KIST IDS 사업 과제

## 과제 정보 (참고용 요약)

**사업명**: 전략연구사업 — 자율 구성 모듈형 휴머노이드 개발단
**주관연구개발기관**: 한국과학기술연구원 (연구책임자 황동현, donghyun@kist.re.kr)
**성격**: 모듈형 휴머노이드의 "자율 구성"(신체 조합·제어 재구성)을 AI/HW/SW 3개 세부과제로 나눠 개발하는 다기관 컨소시엄. 2026-2030 (60개월), 국제공동연구(NC State University) 포함.

**세부과제 구성**

| 세부과제 | 주제 | 참여기관 |
|---|---|---|
| 1 | 최적 신체 자율 구성 AI 에이전트 개발 | 한국생산기술연구원(공동, 안범모 외), 서울대학교(위탁, 주한별 외) |
| 2 | 가변 조합 가능 모듈형 휴머노이드 HW 개발 | 아주대학교(공동, 최영만 외), 국민대학교(위탁, 조백규 외), **명지대학교(위탁, 델가도 라이마리우스 외 10명) ← 우리 담당** |
| 3 | 시행착오 기반 작업 지능 증강 SW 개발 | NC State University(국제공동, 이재민 외), 위탁기관 미정 (2029-2030 합류) |

**우리(명지대) 담당 세부 주제**
- 연구책임자: 델가도 라이마리우스 (w/ 박성우)
- 참여기간: '26.01.01.~'30.12.31. (60개월)
- 연구비: 4억원 (0.8억원/년)
- 주제명: 자율 구성 모듈형 휴머노이드를 위한 신체 토폴로지 인식 및 실시간 제어 재구성 아키텍처 연구
- 최종 목표: 구성 모듈의 metadata와 device signal/status를 기반으로 모듈형 휴머노이드의 신체 topology와 capability를 자동 인식하고, 이를 실시간 제어 프레임워크와 Sim2Real 환경에 반영하여 제어 가능 상태 진입, 동적 재구성 및 조인트 구동 검증이 가능한 HW/SW 통합 아키텍처를 개발

RAIMLAB(명지대)은 세부과제2 — **모듈형 HW 그룹** 소속으로 확인됨.

## 목표
모듈화는 원래 범용성을 위한 것이었으나 방향 수정됨 — **단일 task를 제대로 수행하는 것을 2028년 안에 실증**하는 것이 목표. 이 과제에서 실증하지 못하면 AI 로봇 시장 자체의 미래가 불투명해질 수 있다는 위기감이 있음.

연구단 그룹 구성 (3개 세부과제 = 3개 그룹)
- 신체구성 AI 그룹
- 모듈형 HW 그룹 (**우리 소속**)
- 조작지능 SW 그룹
