### 시계열 멀티모달 (텍스트/테이블 + 시계열)
- [[Language in the Flow of Time - Time-Series Paired Texts Weaved into a Unified Temporal Narrative]] (2026, ICLR, IF: N/A·학회논문) — 텍스트를 시계열의 추가 변수(auxiliary variable)로 다루는 TaTS 제안, 기존 수치 전용 모델에 구조 변경 없이 plug-in (코드 공개)
	- 텍스트 정보를 시계열 모델에 자연스럽게 입히기 위해 텍스트 임베딩을 시계열의 또 다른 수치 변수(추가 채널)처럼 다룸
	- 보통 시계열 데이터와 텍스트를 함께 다룰 때는 두 가지 방식 텍스트 프롬프트 방식(Input Fusion,시계열 수치를 글자로 바꿔서 LLM에 통째로 넣음), 복잡한 크로스 어텐션 방식 (Intermediate Fusion, 모델 구조가 무거워지고 학습이 까다로움)
	→ 굳이 시계열 모델의 구조를 바꿀 필요 없이, 텍스트 정보를 수치 시계열과 똑같은 형태(차원)로 변환
	TS-Rep: Self-supervised time series representation learning from robot sensor data
데이터로부터 자기지도 방식으로 시계열 표현을 학습

- [[MOAT - Multi-Modal Augmented Time Series Forecasting]] (2024, OpenReview preprint·ICLR 2024 제출작, IF: N/A) — feature-wise+sample-wise augmentation과 모달리티 전반 trend-seasonal decomposition으로 데이터 희소 상황의 예측 성능 개선
	- 멀티모달 시계열 예측을 위한 2단계 프레임워크를 도입.
	- 1단계에서는 분해된 시계열과 텍스트 임베딩으로부터 예측을 생성하도록 모델을 최적화.
	- 2단계에서는 MLP를 통한 오프라인 종합(synthesis)을 적용하여 서로 다른 구성 요소들을 동적으로 융합하고, 상대적 기여도에 기반한 최종 예측을 산출.
