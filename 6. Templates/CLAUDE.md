# Templates/

## 목적과 역할
Templater 플러그인과 함께 사용할 **노트 템플릿**을 보관하는 공간입니다. 새 노트를 만들 때 구조를 일관되게 유지하기 위해 사용합니다.

## 어떤 노트가 들어가는가
- 데일리 노트 템플릿
- 프로젝트 개요 템플릿 (`1. Projects/`용)
- Literature 노트 템플릿 (서지 메타데이터 포함, `5. Zettelkasten/10. Literature/`용)
- Permanent 노트 템플릿 (`5. Zettelkasten/20. Permanent/`용)

## 작업 방식과 규칙
- 템플릿 파일 자체는 실제 콘텐츠가 아니므로 이 폴더 밖에서 참고 노트로 사용하지 않습니다.
- 템플릿 구조를 변경하면 해당 템플릿을 사용하는 폴더의 CLAUDE.md 규칙(예: Literature의 서지 메타데이터 형식)과 일치하는지 함께 확인합니다.
- 새로운 노트 유형이 반복적으로 필요해지면 이곳에 템플릿을 추가합니다.
