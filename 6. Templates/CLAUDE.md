# Templates/

## 목적과 역할
Templater 플러그인과 함께 사용할 템플릿을 보관하는 공간입니다. 두 종류가 섞여 있습니다.
1. **노트 형식 템플릿** — 새 노트를 만들 때 골격으로 쓰는 템플릿
2. **텍스트 서식 스니펫** — 선택한 텍스트를 감싸거나 변형하는 짧은 템플릿, 단축키에 연결해서 씀 (예: `텍스트 색상 강조.md`)

Templater 설정: `templates_folder`가 이 폴더로 지정되어 있음.

## 작업 방식과 규칙
- **노트 형식 템플릿**은 미리 여러 개 만들어두지 않습니다. 같은 형식의 노트를 3번 이상 반복해서 쓰게 됐을 때만 템플릿으로 추출합니다.
- **텍스트 서식 스니펫**은 이 규칙에서 예외입니다 — 노트가 아니라 단축키로 즉시 실행할 반복 작업(예: 텍스트 색칠)이라, 필요하다고 판단되면 바로 만들어도 됩니다.
- 단축키에 연결하려면: 이 폴더에 템플릿 파일을 만든 뒤, `.obsidian/plugins/templater-obsidian/data.json`의 `enabled_templates_hotkeys` 배열에 `"6. Templates/[파일명].md"` 형태로 경로를 추가 → Obsidian 설정 → Hotkeys에서 "Templater: Insert 6. Templates/[파일명]" 커맨드를 검색해 원하는 키 지정.
- 선택한 텍스트를 감싸는 스니펫은 템플릿 안에서 `<% tp.file.selection() %>`로 현재 선택 영역을 가져와 감싼다 (선택된 상태에서 실행하면 선택 영역이 결과로 치환됨).
- 템플릿이 실제로 쓰이지 않게 되면 지웁니다.


## 사용자가 해야 할 것
사용법 (마지막 한 단계만 Obsidian에서 직접):
1. Obsidian 재시작 또는 설정 → 커뮤니티 플러그인에서 Templater 새로고침
2. 설정 → Hotkeys → "Templater: Insert 6. Templates/밑줄" 검색
3. 원하는 단축키 지정 (예: Ctrl+U)
