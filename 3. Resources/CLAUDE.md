# Resources/

## 목적과 역할
특정 프로젝트나 영역에 즉시 속하지는 않지만 **향후 참고할 가치가 있는 주제별 자료**를 모아두는 공간입니다. PARA 방법론의 "R"에 해당합니다.

## 어떤 노트가 들어가는가
- 관심 주제별로 정리한 자료 모음 (예: `3. Resources/타이포그래피/`, `3. Resources/머신러닝 툴링/`)
- 스크랩, 클리핑, 링크 모음, 체크리스트, 참고 매뉴얼
- 특정 프로젝트에 종속되지 않는 범용 자료

## 작업 방식과 규칙
- `5. Zettelkasten/10. Literature/`와 혼동하지 않습니다: Literature는 하나의 원천(책/논문/글)을 읽고 남긴 **가공 전 요약 노트**이고, Resources는 여러 원천에서 모은 자료를 주제별로 **재구성/정리한 참고 창고**입니다.
- 나중에 다시 찾아볼 가능성이 있는 자료만 남기고, 일회성 정보는 두지 않습니다.
- 자료에서 나온 핵심 통찰이 자신만의 언어로 정리할 가치가 있다면 `5. Zettelkasten/20. Permanent/`로 승격시켜 지식화합니다.
- 더 이상 유효하지 않거나 쓸모없어진 자료는 `4. Archive/`로 이동하거나 삭제합니다.
