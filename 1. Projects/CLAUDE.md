# Projects/

## 목적과 역할
**마감일과 명확한 완료 조건이 있는** 단기 프로젝트를 관리하는 공간입니다. PARA 방법론의 "P"에 해당하며, "언제 끝나는가"가 분명한 작업만 이곳에 둡니다.

## 어떤 노트가 들어가는가
- 프로젝트별 개요 노트 (목표, 마감일, 이해관계자, 진행 상태)
- 프로젝트 진행 중 작성하는 작업 로그, 체크리스트, 회의록
- 프로젝트별 하위 폴더 (예: `1. Projects/2026 논문 제출/`)로 구성

## 작업 방식과 규칙
- 프로젝트는 "완료 조건"이 명확해야 이곳에 생성합니다. 완료 조건이 없으면 `2. Areas/`로 보냅니다.
- 프로젝트 하나당 폴더 하나를 기본으로 하고, 폴더 안에 개요 노트(예: `00. 개요.md`)를 둡니다.
- 프로젝트 진행 중 얻은 통찰이나 재사용 가능한 지식은 `5. Zettelkasten/00. Inbox/`로 옮겨 별도로 정제합니다. Projects 폴더 자체는 지식 축적용이 아니라 실행용 작업대입니다.
- 프로젝트가 끝나면 폴더 전체를 `4. Archive/`로 이동하고 이곳에는 남기지 않습니다.
