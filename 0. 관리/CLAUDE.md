# 0. 관리/

## 목적과 역할
vault 전체를 관리하기 위한 **단일 진입점**입니다. 개인 공부/논문·프로젝트/Paper review/일상 네 파트와는 별개로, 이들을 가로지르는 todo와 현황을 여기서 모아봅니다.

## 어떤 노트가 들어가는가
- `00_Dashboard.md`: Dataview로 전체 todo, 최근 활동, 프로젝트 현황을 자동 수집하는 대시보드. 콘텐츠를 직접 담지 않고 집계만 한다.
- `Todo.md`: 1/2/3/4 어디에도 속하지 않는 잡다한 할 일. PARA Area 메모 성격이지만, 개인적인 메모(교수님·기업 정보, 장기 목표 등)는 사용자가 `4. 일상/`으로 옮겨 관리하기로 함 — 이 폴더에는 굳이 두지 않는다.
- 1/2/3 각 파트를 요약해서 보여주는 인덱스 노트(`1. 개인 공부.md`, `2. 논문·프로젝트.md`, `3. Paper review.md`). DataviewJS로 자동 생성하며, 원본 폴더에 새 폴더/노트가 생기면 다음에 열 때 자동으로 반영되므로 수동으로 갱신하지 않는다. 파트마다 구조가 다르다:
  - `1. 개인 공부.md`: 하위 폴더(예: EtherCAT)를 제목2(`dv.header(2, ...)`)로, 그 안의 노트(예: State Machine)를 불릿 링크로 나열
  - `2. 논문·프로젝트.md`: 프로젝트별로 해당 프로젝트 담당 노트(폴더와 동일한 이름)에 링크되는 불릿 목록
  - `3. Paper review.md`: 세미나 리뷰한 논문별로, 해당 논문 폴더 안의 메인 리뷰 노트(폴더명과 동일한 노트)에 직접 링크되는 불릿 목록. 프로젝트 레퍼런스(`[프로젝트명] refs/`)는 대상 아님
  - `4. 일상`은 인덱스 대상에서 제외 (데일리 노트라 목록화 필요성 낮음)
  - DataviewJS 사용을 위해 `enableDataviewJs` 설정이 켜져 있어야 한다.

## 작업 방식과 규칙
- `00_Dashboard.md` 자체에는 콘텐츠를 직접 쓰지 않습니다. Dashboard는 이 폴더를 포함한 vault 전체를 가리키거나 집계하는 용도로만 씁니다.
- 1/2/3/4 중 하나에 속하는 내용(공부 주제, 특정 논문/프로젝트, 세미나 리뷰, 일상)이면 그쪽 폴더에 두고 여기서는 링크만 겁니다.
- `Todo.md` 같은 노트 안의 할 일은 `- [ ]` 체크박스로 적으면 Dashboard의 전체 Todo에 자동으로 잡힙니다.
- Dashboard는 폴더 구조가 바뀌면 Dataview 쿼리의 FROM 경로도 함께 업데이트합니다.
