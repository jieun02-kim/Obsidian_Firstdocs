# 3. Paper review

`3. Paper review` 폴더의 세미나 리뷰 논문 목록(폴더명과 동일한 메인 리뷰 노트만). 각 항목은 리뷰 노트 본문으로 바로 링크된다. 새 리뷰 노트가 생기면 다음에 열 때 자동으로 반영된다 — 직접 수정할 필요 없음. 프로젝트 레퍼런스(`[프로젝트명] refs/`)는 여기 나타나지 않는다.

```dataviewjs
const papers = dv.pages('"3. Paper review"')
  .where(p => p.file.name === p.file.folder.split("/").pop())
  .sort(p => p.file.name)

dv.list(papers.map(p => p.file.link))
```
