# 3. Seminar

`3. Seminar` 폴더에서 리뷰한 논문 목록. 각 항목은 리뷰 노트 본문으로 바로 링크된다. 새 리뷰 노트가 생기면 다음에 열 때 자동으로 반영된다 — 직접 수정할 필요 없음.

```dataviewjs
const papers = dv.pages('"3. Seminar"')
  .where(p => p.file.name === p.file.folder.split("/").pop())
  .sort(p => p.file.name)

dv.list(papers.map(p => p.file.link))
```
