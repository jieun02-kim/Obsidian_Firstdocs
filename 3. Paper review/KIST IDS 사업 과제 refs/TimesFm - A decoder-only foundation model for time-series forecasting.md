## 핵심 요약
- 역할: 시계열 데이터의 미래 패턴을 예측하여 이상(Anomaly) 유무를 판단하는 시계열 파운데이션 모델
- 구글 리서치 개발. 다양한 영역(금융, 데이터 센터, 센서 데이터 등)에서의 Zero-shot 예측 성능
- 시계열 데이터를 일정 길이의 패치(Patch) 단위로 나누어 트랜스포머(Transformer) 구조로 입출력
