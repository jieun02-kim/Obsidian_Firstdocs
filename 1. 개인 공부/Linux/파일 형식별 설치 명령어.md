# 리눅스 파일 형식별 설치 명령어

## .deb (Debian/Ubuntu 계열)
```bash
sudo dpkg -i 파일이름.deb
sudo apt-get install -f   # 의존성 누락 시 자동 해결
```
또는 한 번에:
```bash
sudo apt install ./파일이름.deb
```
- `./`를 꼭 붙여야 apt가 로컬 파일 경로로 인식함 (안 붙이면 저장소에서 같은 이름의 패키지를 찾으려 함)
- `apt install ./파일.deb`는 설치 전에 의존성을 먼저 계산해서 한 번에 설치 (실패 시 깔끔하게 롤백). `dpkg -i` → `apt-get install -f`는 일단 강제 설치 후 나중에 고치는 방식이라 중간에 broken 상태를 거침. 설치가 정상적으로 끝나면 최종 결과는 동일.

## .rpm (Fedora, RHEL, CentOS 계열)
```bash
sudo rpm -i 파일이름.rpm        # 저수준 설치 (의존성 자동 해결 안 됨)
sudo dnf install ./파일이름.rpm  # 의존성까지 자동 해결 (최신, 권장)
sudo yum install ./파일이름.rpm  # dnf 이전 버전 배포판
```

## .tar.gz / .tar.xz / .tar.bz2 (압축된 소스코드 또는 바이너리)
```bash
tar -xzvf 파일이름.tar.gz   # gz 압축 해제 (-x 추출, -z gzip, -v 진행표시, -f 파일지정)
tar -xJvf 파일이름.tar.xz   # xz 압축 해제 (-J가 xz 옵션)
cd 압축해제된폴더
./configure && make && sudo make install   # 소스코드인 경우 빌드 후 설치
```

## .AppImage (설치 없이 바로 실행되는 휴대용 실행파일)
```bash
chmod +x 파일이름.AppImage
./파일이름.AppImage
```

## .snap
```bash
sudo snap install 파일이름.snap --dangerous
# --dangerous: 서명 검증 안 된 로컬 파일을 강제로 설치할 때 필요
```

## .flatpak / .flatpakref
```bash
flatpak install 파일이름.flatpak
```

## .run (NVIDIA 드라이버 등에서 흔함, 자체 설치 스크립트가 내장된 바이너리)
```bash
chmod +x 파일이름.run
sudo ./파일이름.run
```

## .sh (셸 스크립트로 배포되는 설치 프로그램, 예: 아나콘다)
```bash
chmod +x 파일이름.sh
./파일이름.sh
```

## .whl (파이썬 패키지)
```bash
pip install 파일이름.whl
```

## .zip (압축된 바이너리/포터블 앱인 경우가 많음)
```bash
unzip 파일이름.zip -d 원하는폴더
```

## 참고: chmod +x
"설치"가 아니라 파일에 **실행 권한**을 부여하는 것. 다운로드된 파일은 기본적으로 실행 권한이 꺼져 있어서, 실행형 파일(AppImage, run, sh)은 먼저 이 권한을 켜줘야 함.
