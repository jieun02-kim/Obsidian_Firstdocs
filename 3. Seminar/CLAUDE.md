# 3. Seminar/

## 목적과 역할
연구실 세미나에서 리뷰하는 논문을 정리하는 공간입니다. `2. 논문·프로젝트`의 `refs/`와 달리, 특정 프로젝트에 종속되지 않고 세미나 발표/리뷰 단위로 쌓입니다.

## 폴더 구조
```
3. Seminar/
  [번호. 논문명]/       ← 예: "1. PANCS Proactive self-adaptation for nonlinear cyber–physical systems"
    [번호. 논문명].md   ← 메인 리뷰 노트. 폴더명과 파일명이 동일
    refs.md            ← 이 논문 References 전체 정리. 메인 노트와 함께 생성
    (부가 노트들)        ← 이 논문에 관한 그 외 추가 노트 (필요할 때만 생성)
```

## 어떤 노트가 들어가는가
- 세미나에서 리뷰할 논문마다 `[번호. 논문명]` 폴더 하나. 번호는 리뷰한 순서대로 매긴다 (`1.`, `2.`, ...).
- 메인 리뷰 노트: 폴더와 같은 이름의 `.md` 파일 하나. 발표/리뷰용 보조자료이므로 `2. 논문·프로젝트/refs/`와 달리 **자신의 언어로 재구성한 요약이 아니라, 뜻이 왜곡되지 않도록 원문을 최대한 보존한 요약·번역·설명**을 담습니다.
- `refs.md`: 메인 리뷰 노트를 만들 때 항상 같이 생성한다. 그 논문의 References에 실린 **모든 참조 논문**을 표로 나열하고(논문 | 관계성 | 노트), 원문에서 실제로 논의된(비교 대상/선행 연구/모델 출처 등) 참조는 "관계성" 칸에 그 내용을 적는다. 아직 정리할 내용이 없는 참조는 "관계성" 칸을 비워두고 이름만 올려둔다.
- 그 외 부가 노트: 같은 폴더 안에, 필요해질 때만 추가한다 (수식 정리, 실험 재현, 질문 리스트 등). 메인 리뷰 노트의 "관련 노트" 섹션에서 링크로 연결한다.

## 참조 논문에 대해 상세 노트가 필요해지면
`refs.md`의 항목은 표 안의 텍스트일 뿐, 그 자체로는 노트가 아니다. 나중에 그 참조 논문을 실제로 읽거나 상세 내용을 정리하게 되면:
1. 별도 노트를 새로 만든다 (어디에 둘지는 성격에 따라 판단 — 이 세미나 리뷰와 강하게 묶이면 같은 폴더에, 여러 리뷰에서 재사용될 일반 레퍼런스면 별도 위치를 그때 정한다).
2. `refs.md`의 해당 행 "노트" 칸에 `[[노트 이름]]`으로 링크한다.
`refs.md` 표 자체를 지우거나 다시 쓰지 않고, 항상 "노트" 칸만 채워나간다.

## 작업 방식과 규칙
- 원본 PDF/자료는 Z: 드라이브 등 원래 위치에 그대로 두고, 여기서는 리뷰 노트만 작성합니다.
- 섹션/문장 단위로 원문 표현을 살려 요약하거나 번역하고, 필요하면 그 아래에 설명을 덧붙이는 방식으로 씁니다. 임의로 압축·재해석해서 원문 의미를 바꾸지 않습니다.
- 필수 속성(메인 리뷰 노트): `type: literature`, `status`, `updated` (루트 CLAUDE.md 공통 속성 스키마 참고)
- `0. 관리/3. Seminar.md` 인덱스는 폴더명과 파일명이 같은 노트(메인 리뷰 노트)만 자동으로 찾아 링크한다. 관련 논문 노트·부가 노트는 인덱스에 나타나지 않으므로 반드시 메인 노트에서 링크해 둘 것.
