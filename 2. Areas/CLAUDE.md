# Areas/

## 목적과 역할
**마감일은 없지만 지속적으로 관리해야 하는 책임 영역**을 담는 공간입니다. PARA 방법론의 "A"에 해당하며, 건강, 재정, 커리어, 인간관계처럼 "끝나지 않는" 영역을 다룹니다.

## 어떤 노트가 들어가는가
- 영역별 대시보드/현황 노트 (예: `건강.md`, `재정.md`, `연구실 운영.md`)
- 해당 영역을 유지하기 위한 기준(standard)이나 루틴 기록
- 정기 리뷰 시 작성하는 점검 노트

## 작업 방식과 규칙
- 영역은 완료되지 않습니다. "이 영역을 잘 유지하고 있는가"를 기준으로 관리합니다.
- 영역을 관리하다가 마감일이 있는 구체적 작업이 생기면 `1. Projects/`에 새 프로젝트로 분리합니다.
- 정기적으로(예: 주간/월간) 리뷰하며 최신 상태를 유지합니다.
- 더 이상 관리할 필요가 없어진 영역은 `4. Archive/`로 이동합니다.
