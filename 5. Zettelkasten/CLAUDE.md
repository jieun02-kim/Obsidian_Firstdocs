# Zettelkasten/

## 목적과 역할
PARA(`1. Projects/2. Areas/3. Resources/4. Archive`)가 "지금 하고 있는 일"을 위한 작업대라면, Zettelkasten은 **시간이 지나도 남는 지식을 축적하고 서로 연결하는 지식 발전소**입니다. 두 체계는 의도적으로 분리되어 있으며, 서로 다른 목적을 가집니다.

## 하위 구조
- `00. Inbox/` — 빠르게 캡처한 미가공 메모
- `10. Literature/` — 외부 원천(책/논문/글/영상)에서 얻은 요약 노트
- `20. Permanent/` — 완전히 소화되어 독립적으로 이해 가능한 영구 지식 노트

## 작업 방식과 규칙
- 노트는 기본적으로 **Inbox → Literature → Permanent** 순서로 정제됩니다. 모든 메모가 이 파이프라인을 거칠 필요는 없지만, 방향은 항상 "미가공 → 정제"입니다.
- 폴더(카테고리)보다 **링크(`[[위키링크]]`)를 통한 연결**을 우선합니다. 노트를 어디에 분류할지 고민하기보다 관련 노트와 연결하는 데 시간을 씁니다.
- PARA 폴더(Projects/Areas/Resources)의 작업 중 얻은 통찰은 즉시 여기로 옮겨 지식으로 승격시킵니다. 반대로 Zettelkasten의 노트를 실행 작업(할 일, 마감)으로 다루지 않습니다.
- Archive로 보내지 않습니다. Zettelkasten의 노트는 오래되어도 계속 연결망의 일부로 남습니다.
