# Zettelkasten/20. Permanent/

## 목적과 역할
완전히 소화되어 **독립적으로 이해 가능한 영구 지식 노트**를 보관하는, Zettelkasten의 핵심 공간입니다.

## 어떤 노트가 들어가는가
- 하나의 노트 = 하나의 아이디어(원자성 원칙)
- 제목만 봐도 내용을 짐작할 수 있는, 자신의 언어로 쓴 완결된 문장/개념
- Inbox나 Literature에서 승격되었거나, 여러 노트를 연결하며 새로 떠오른 통찰

## 작업 방식과 규칙
- 노트는 **원자적**이어야 합니다: 하나의 노트에는 하나의 개념/주장만 담습니다. 여러 아이디어가 섞이면 노트를 분리합니다.
- 반드시 **자신의 언어**로 씁니다. 원천을 그대로 옮긴 것은 Permanent가 아니라 Literature입니다.
- 폴더나 태그로 분류하기보다, 관련된 다른 Permanent 노트와 `[[위키링크]]`로 연결하는 데 집중합니다. 연결이 많을수록 지식망으로서의 가치가 커집니다.
- 한 번 작성했다고 끝나는 것이 아니라, 새로운 연결이나 통찰이 생기면 계속 다듬고 확장합니다.
- 이곳의 노트는 삭제하거나 Archive로 보내지 않습니다. 틀린 내용이 있으면 수정하되, 지식 자체는 계속 누적됩니다.
